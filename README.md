# Lekan
**Vehicle Sales Dashboard Web Application**

**Project Description**

This project is a web application dashboard built using Python and Streamlit that allows users to explore and analyze a dataset of used car advertisements in the United States. The goal of the application is to provide an interactive tool for visualizing vehicle data and understanding patterns in car prices, mileage (odometer readings), and vehicle conditions.

The application includes interactive charts such as histograms and scatter plots that help users explore the distribution of vehicle prices and the relationship between mileage and price. Users can interact with the dashboard using checkboxes to display or hide different visualizations, making it easier to analyze trends in the dataset.

This project demonstrates real-world software development and data analysis skills, including building a web application, performing exploratory data analysis, managing code with GitHub, and deploying a public application to a cloud platform using Render.

## Technologies and Libraries Used

The project was developed using the following tools and libraries:

* Python
* Pandas (data manipulation and analysis)
* Streamlit (web application framework)
* Plotly Express (interactive data visualization)
* Altair (data visualization)
* Git and GitHub (version control)
* Render (cloud deployment)
* Jupyter Notebook (exploratory data analysis)

## Features

* Interactive Streamlit web dashboard
* Histogram of vehicle price distribution
* Scatter plot of price vs odometer
* Checkbox controls to display visualizations
* Exploratory Data Analysis notebook
* Cloud deployment on Render
* Public GitHub repository
